# Ching Chuang | Portfolio

A personal portfolio website showcasing my work and capabilities in UI/UX Design, Product Design, and Digital Experiences.

**Live Website:** [https://cc-amy.github.io/Portfolio_CC/](https://cc-amy.github.io/Portfolio_CC/)

## Overview

This portfolio presents my design philosophy, selected projects, professional experience, and design capabilities.

Designed with a Contemporary Minimalism approach, the website combines a neutral color palette, editorial typography, and thoughtful spacing to create a clean and intuitive browsing experience.

## Sections

- **Home** — Introduction and portfolio navigation
- **About** — Design philosophy and approach
- **Work** — Selected UI/UX and product design projects
- **Experience** — Project experience, design methods, tools, and education
- **Capabilities** — Core design thinking and professional capabilities
- **Contact** — Contact information

## Features

- Responsive layout for desktop and mobile devices
- Interactive navigation and section-based browsing
- Light and dark theme toggle
- Tab-based experience content
- Minimalist visual design with editorial typography

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
